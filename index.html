Slack API Setup & Scopes Guide

To pull real workspace channels, team members, and post messages directly from this app, follow these 4 quick steps:

1

Create a Slack App

Go to api.slack.com/apps and click "Create New App" -> "From scratch". Name it Purchase Requests and select your workspace.

2

Add Bot Token Scopes

Go to OAuth & Permissions sidebar menu. Scroll down to Bot Token Scopes and add these 5 permissions:

channels:read groups:read users:read chat:write chat:write.public
3

Install App to Workspace & Copy Token

Scroll up to top of OAuth & Permissions page, click "Install to Workspace", and copy the Bot User OAuth Token starting with xoxb-.

4

Paste Token & Click Sync

Paste the token into the Workspace Connection bar at top of this page and click "Sync Workspace"!

Browser CORS Note: Slack API enforces CORS when called directly from frontend browsers. If your request gets blocked by browser CORS, you can use a browser extension like Allow CORS, or simply copy the Slack Canvas Markdown generated in 1-click!
